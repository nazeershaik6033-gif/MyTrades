⇅ Backup & Cross-Device Sync
How to use across devices
1. On your current device → click Export Backup → save the .json file
2. Move that file to your other device (WhatsApp, Google Drive, Email, USB)
3. On the new device → open ChartLog → click Import Backup → select the file
4. All your trades, notes & charts will be restored instantly ✓
